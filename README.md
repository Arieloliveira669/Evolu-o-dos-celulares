# 📱 Evolução dos Celulares

Site interativo que conta a história dos celulares, do primeiro protótipo em 1973 até a era da inteligência artificial.

🔗 **Site:** https://arieloliveira669.github.io/Evolu-o-dos-celulares/

## Funcionalidades

- Linha do tempo com 20 marcos históricos, com ficha técnica e curiosidade em cada um
- Busca por nome ou ano e filtro por época
- Botões "Ler mais", "Expandir todos" e curtidas
- Tabela comparativa de aparelhos e gráfico de peso animado
- Seção de curiosidades
- Quiz com 8 perguntas, pontuação e recorde salvo no navegador
- Modo claro e escuro (a escolha fica salva)
- Menu fixo, barra de progresso de leitura e botão de voltar ao topo
- Layout responsivo para celular, tablet e computador
- Acessibilidade: navegação por teclado, link "pular para o conteúdo" e suporte a leitores de tela
- Estilo próprio para impressão

## Tecnologias

- HTML5
- CSS3 (variáveis, grid, flexbox e media queries)
- JavaScript (DOM, IntersectionObserver e localStorage)

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos e responsividade
- `script.js`: dados dos marcos, interações e quiz

## Como abrir

Acesse o link do site acima ou baixe o repositório e abra o `index.html` no navegador.
